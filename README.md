## How to Play

1. Open Creeper Sweeper in a web browser.
2. Begin a puzzle board.
3. Study the grid and apply the visible clues to identify hidden hazards.
4. Flag cells that you believe contain Creepers.
5. Reveal cells with care and keep solving until the board is complete.

A current desktop or mobile browser with JavaScript turned on provides the intended experience.
